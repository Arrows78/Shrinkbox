Shrinkbox 0.1.0 is the first release: it makes images, videos, audio files and PDFs smaller, from a drop zone, the clipboard, watched folders or the command line.

### Highlights

- **Images, videos, audio and PDFs**: compression levels, crop, downscale, format conversion (HEIC to JPEG, MOV to MP4 or GIF, WAV to M4A…), target size, metadata removal and watermarks. It needs no other tool; `ffmpeg`, Ghostscript and a few others add formats and stronger compression when they are installed.
- **Floating results** with the saving of each file and buttons to restore the original, crop, convert, downscale, fit under a size or open Quick Look.
- **Drop zone, preset zones and batch mode**, a **clipboard optimiser** and **watched folders** with loop protection.
- **Pipelines**: chain steps with filters, save them, attach them to a folder or the clipboard, and run them from the command line.
- **Command line and MCP server** for scripts and AI apps, with switches that keep changes under your control.
- **English, French, Spanish and German**.

### Good to know

- The Spanish and German texts are machine translations that no native speaker has reviewed.
- Releases are signed ad hoc and not notarised: macOS blocks the first launch (see the README for the one-line fix).
